# Local Codex route × language pilots

Use this mode only for an explicitly requested local Codex experiment. It is a separate product condition from ChatGPT Web; keep their observations and model/effort labels separate.

## Execution and context

Prefer the authenticated desktop create_thread interface for fresh saved local tasks when available. Set the user-selected model and effort explicitly. Use projectless tasks with separate neutral directories/titles, the exact frozen prompt and no parent fork. Collaboration agents are suitable for independent rating and review; they are not a substitute for user-requested fresh saved test tasks.

Verify the returned local host, saved-session UUID/cwd and per-turn model/effort metadata. A model catalog entry or requested label alone is insufficient. Record the app's delivery wrapper, automatically supplied context, any tool calls, and deviations. A separately launched CLI reporting Not logged in does not establish that the desktop account is logged out. Do not transfer credentials or switch products/accounts to make a run appear comparable.

Keep the private answer key, old responses and scoring instructions outside the tested directories. If measuring only automatically supplied context, explicitly forbid tools in the frozen task and audit actual calls. If measuring retrieval as well, preregister that different tool-enabled condition separately. More claimed access or stronger confidence is not evidence of additional memory. When observable, hash the supplied memory summary before deleting each task; identical hashes show identical observed summaries, not identical hidden provider context. Missing hashes remain missing.

## Route and permissions

Verify the local process and its effective proxy/tunnel conditions, selected routes and established connection addresses, plus external country checks before and after each answer. Browser egress is not proof of local Codex egress. Account region, language, backend assignment and VPN egress are different variables.

Native application approval and task network permissions are separate. Recheck the current task's effective rights after an environment change; global defaults may differ. Do not reinterpret a permission, authentication or quota failure as a model refusal or switch regions to bypass it.

Prefer a supported client interface. NordVPN Windows documents connection by country or explicit server; confirm installed help/current documentation before use. If a controller changes, record when and retain the same response-level route checks. Distinguish requested server names, contemporaneously observed names, and later recent-server evidence. Hold egress fixed within each language pair and restore the observed baseline. A restored server can assign a new IP.

## Custody and lifecycle

Capture the complete original answer privately, not the truncated preview returned by a status tool. Verify exact prompt equality, full response status, model metadata and file hashes before cleanup. If user-authorized deletion is required, validate that the desktop task UUID matches the local saved-session UUID and cwd before invoking the supported exact-UUID deletion interface. Verify the receipt and saved-state absence. Archiving is not deletion. Do not delete unrelated tasks or change account memory.

For blinded ratings, verify every supplied file against its retained original and check non-whitespace length. A rater's failed read is not an empty model answer. Preserve the initial rating and any explicit correction separately before unblinding; never silently overwrite disagreement.

## Paired descriptive analysis

With one native-language and one German response per route, report each pair separately; German twice is a repetition control. Do not pool different native languages into one effect or treat correlated subquestions as independent country trials. Do not report p-values or confidence intervals from these pseudo-replicates.

Use the frozen rubric. Keep usable historical context, grounded directness, descriptive style and substantive engagement separate. Style needs paired categorical transitions, not a summed freedom score. Record refusal, information gaps and technical failures distinctly. Exclude non-rateable pairs from agreement denominators and propagate missing values through aggregates.

Non-graphic adult-topic completion and a declared explicit-content boundary are different endpoints. A statement about what a model would refuse is not an observed generation test. Report the tested content classes and sample limitations rather than a universal country ranking. Preserve model-assisted rater uncertainty and withhold personal originals/keys from public releases.
